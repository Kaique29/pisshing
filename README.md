# pisshing
Escopo
Tipo de teste: Simulação de phishing (credential harvesting)
Ambiente: Rede interna de laboratório/teste
Ferramenta utilizada: Social-Engineering Toolkit (SET)
Alvo: Colaborador(es) selecionado(s) para o exercício, dentro do escopo autorizado
Autorização: Teste realizado sob autorização prévia, como exercício de treinamento

Clonagem de site Utilização do módulo Website Attack Vectors → Credential Harvester do SET para clonar a página de login de referência, hospedada localmente no IP 
Domínio de teste Configuração de um domínio similar ao domínio real
